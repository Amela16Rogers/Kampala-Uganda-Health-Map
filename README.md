# Kampala Health Centers GIS Web Application

A responsive web application displaying health centers in Kampala District using Leaflet.js.

## Features

- Interactive map with health center locations
- Search functionality by name
- Responsive design for mobile and desktop
- Popup information for each health center
- Current location detection (bonus feature)
- GeoJSON data support (bonus feature)

## Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Mapping**: Leaflet.js
- **Data Format**: GeoJSON
- **Icons**: Leaflet Color Markers
- **Tiles**: OpenStreetMap

## Dataset Source

Health center data was compiled from:
- OpenStreetMap
- Uganda Ministry of Health directories
- Manual research and verification
